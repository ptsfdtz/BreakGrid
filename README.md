# BREAKGRID · 方块破坏王

React + TypeScript + Canvas 2D 的手机端打砖块游戏。包含24 张自由选择的地图、10 点耐久灰块、1 点耐久绿块、随机技能掉落、无球数上限的分裂爆发，以及本地最佳纪录。

界面以战场为主，只保留地图入口、数字状态和点击战场发球。地图采用 38×43 网格，每张地图超过 1,100 个方块；入口统一位于底部，位置、宽度和隧道长度各不相同，通过错位弯道连接球仓，增加进出难度和内部连续反弹。设置、选图均通过图标打开，选图支持双列预览和纵向滚动。

## 启动

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址。手机与电脑在同一局域网时，可使用终端显示的 Network 地址（必要时允许系统防火墙访问）。

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

## GitHub Pages 部署

1. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
2. 将部署配置提交并推送到 `main`，工作流会自动安装依赖、测试、构建和发布。也可在 **Actions → Deploy GitHub Pages → Run workflow** 手动运行。
3. 首次发布成功后访问 https://ptsfdtz.github.io/BreakGrid/ 。实际地址也会显示在工作流的 `github-pages` 环境中。

工作流使用 Node.js 24、pnpm 11.25.0 和锁文件安装依赖。Vite 从 Pages 配置获取站点路径，因此 `/BreakGrid/` 下的资源链接可正常访问；本地开发仍使用 `/`。如果配置自定义域名，无需手动修改资源路径。

本地验证 Pages 路径（PowerShell）：

```powershell
$env:VITE_BASE_PATH = '/BreakGrid/'
pnpm build
Remove-Item Env:VITE_BASE_PATH
pnpm preview --base /BreakGrid/
```

预览时打开终端地址下的 `/BreakGrid/`。工作流只发布 `dist`，不发布源码或预览截图。

## 操作

- 轻点战场或按空格发射一颗球，手指拖动 / 鼠标移动 / 左右方向键控制挡板。
- 接住掉落道具立即触发：紫色让所有现有球各自变成三颗，不设球数上限；金色从挡板补发三颗。每种技能独立冷却 0.5 秒，冷却内同类道具消耗但不重复触发，暂停时冷却停止。技能无需点击或按键。首次发射、掉球补发和重试均只发射一颗球，多球由接住道具产生。
- 所有球落下才扣一次机会；每关三次机会，补发球保留破坏进度，重试本关全部重置。
- 清除全部绿色方块即完成当前地图，所有地图从一开始即可自由选择，灰墙不必全部清除。进度条只统计绿块。浏览器 localStorage 保存最佳得分、音效及触觉反馈设置；不跨设备同步。
- 切后台、失去窗口焦点或战场尺寸改变时暂停，需手动继续。

## 安装到手机桌面（PWA）

- 发布到 GitHub Pages 后，用手机浏览器打开 HTTPS 地址。设置中的下载图标可发起安装；不支持直接安装提示的浏览器会显示添加到桌面的路径。
- Android Chrome：点设置中的下载图标，或浏览器菜单 → 安装应用 / 添加到主屏幕。
- iPhone / iPad：在 Safari 中打开，分享 → 添加到主屏幕。主屏幕图标启动后以独立应用窗口运行。
- 首次在线打开并完成资源缓存后，可离线打开和游玩。应用更新准备好时，设置中出现更新图标；点击后刷新，不会在游玩中自动刷新。
- 本地 `pnpm dev` 不启用离线缓存；验证安装与缓存需使用 `pnpm build` 和 `pnpm preview`。局域网 HTTP 地址不支持 PWA 安装；手机安装验证请使用 Pages 的 HTTPS 地址。

## 结构

`src/game` 是与 React 独立的物理、地图、渲染、存储及 Web Audio 模块。物理使用 120 Hz 固定步长，进一步细分位移并以网格索引检测附近砖块。React 负责界面，每约 90ms 获取一次状态快照。逻辑场地 420×590，Canvas 根据布局及设备像素比缩放。网页字体使用在线字体服务，离线时回退系统字体；游戏无需联网。

## 添加地图

编辑 `src/game/maps.json`，追加配置即可，无需修改选图界面或存档长度。数组顺序对应地图编号；为保留旧地图成绩，请在末尾追加，避免重排已有地图。

```json
{
  "id": "map-25",
  "name": "新地图",
  "pockets": [[13, 16, 12, 14]],
  "walls": [[18, 1, 1, 12]],
  "entrances": [
    { "side": "bottom", "position": 18, "width": 1, "depth": 10, "bend": 3 }
  ]
}
```

坐标单位为网格，地图宽 38 格、高 43 格。`pockets` 是空白区域，`walls` 是灰墙区域，均采用 `[列, 行, 宽, 高]`。其余区域自动铺绿块，外围和空白区域边缘自动铺十次耐久灰块。

`entrances` 可配置多个入口：`side` 固定为 `bottom`；`position` 为底边从左计的位置；`width` 为入口宽度，推荐 1–3 格；`depth` 为向上延伸长度，现有地图为 6–17 格；`bend` 为转弯偏移，正数向右，负数向左。入口、错位通道和内部小仓自动生成。入口与通道应保持在网格内，推荐位置离两端至少 5 格。预览与实际地图使用同一生成函数。

手机控制支持底部触控区及战场周围空白区域。手指按下时保持挡板原位，左右相对滑动控制挡板；可在挡板下方操作，避免遮挡。触控过程不会滚动页面，离开触控区仍持续捕获拖动。
