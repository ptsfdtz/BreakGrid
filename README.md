# BREAKGRID · 方块破坏王

React + TypeScript + Canvas 2D 的手机端打砖块游戏。包含六个关卡、10 点耐久灰块、1 点耐久绿块、随机技能掉落、最多 96 球的分裂爆发，以及本地关卡解锁与最佳纪录。

界面以战场为主，只保留关卡入口、数字状态和点击战场发球。地图采用 38×43 网格，每关超过 1,100 个方块；单格底部入口通过错位弯道连接封闭球仓，增加进出难度和内部连续反弹。设置、选关均通过图标打开。

## 启动

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址。手机与电脑在同一局域网时，可使用终端显示的 Network 地址（必要时允许系统防火墙访问）。

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

## 操作

- 轻点战场或按空格发射一颗球，手指拖动 / 鼠标移动 / 左右方向键控制挡板。
- 接住掉落道具立即触发：紫色让现有球各自变成三颗，金色从挡板补发三颗。最多 96 球，接近上限时仅补充剩余空位，达到上限不再生成。技能无需点击或按键。首次发射、掉球补发和重试均只发射一颗球，多球由接住道具产生。
- 所有球落下才扣一次机会；每关三次机会，补发球保留破坏进度，重试本关全部重置。
- 清除全部方块解锁下一关。浏览器 localStorage 保存解锁、最佳得分、音效及触觉反馈设置；不跨设备同步。
- 切后台、失去窗口焦点或战场尺寸改变时暂停，需手动继续。

## 结构

`src/game` 是与 React 独立的物理、地图、渲染、存储及 Web Audio 模块。物理使用 120 Hz 固定步长，进一步细分位移并以网格索引检测附近砖块。React 负责界面，每约 90ms 获取一次状态快照。逻辑场地 420×590，Canvas 根据布局及设备像素比缩放。网页字体使用在线字体服务，离线时回退系统字体；游戏无需联网。
